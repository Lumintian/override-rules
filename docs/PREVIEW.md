# 本地开发预览

Override Lab 是独立的本地开发工具，不是 Mihomo 控制面板。它执行当前工作区的改名和覆写源码，以策略组卡片、名称对照和配置文本展示结果，无须启动 Mihomo。

## 启动

安装项目依赖后运行：

```bash
npm run preview
```

打开终端显示的地址，默认是 **http://127.0.0.1:8787**。端口冲突时：

```bash
npm run preview -- --port=8788
```

工具复用已有的 `tsx`、`esbuild` 和 `yaml`，没有新增第三方依赖。不需要先运行 `npm run build`，也不会写入或依赖根目录的构建产物。页面、编译结果和导入内容均不持久化，关闭服务即可结束。

## 使用流程

1. **提供节点**：粘贴每行一个节点名称，或选择“链接导入”并填写 HTTP(S) 原始链接。也可以直接粘贴完整 Clash YAML / JSON。
2. **设置改名参数**：与 `rename.min.js` 的 Fragment 参数对应，不需要写完整脚本 URL。可关闭“启用”，直接预览覆写。
3. **设置覆写参数**：例如 `grouptype=1&threshold=2&us=2&sg=1`。
4. **查看结果**：切换“策略组”“名称对照”“生成配置”；可搜索名称、复制 YAML/JSON 或手动下载配置。

“载入示例”每次生成一组虚构节点名称，不含仓库或真实订阅中的节点。初始改名参数为 `flag&blgd&bl&nm&clear`，其中 **clear 已显式开启**，会由真实改名脚本过滤流量、到期等提示行。删除 `clear` 或设为 `clear=false` 可以对比差异。预览器自身不会擅自丢弃这些非空行。

参数支持前导 `#`、裸布尔开关及显式 true/false、1/0。`blkey=自建+落地` 中的 `+` 保持为关键词分隔符，不转换为空格。未知参数仍交由实际脚本处理。

### 自动更新

开启“自动更新”时：

- 编辑文本或参数后，约 450 毫秒自动执行预览。
- 每约 1.5 秒检查 `src/**/*.ts` 与 `scripts/substore/rename.ts` 的内容指纹，源码变化后重新编译并预览。
- 编译 / 执行失败会显示错误并清除旧结果；修复源码后自动恢复，不伪装成最新的成功结果。
- 页面在后台时暂停源码轮询。关闭“自动更新”后可手动点击按钮。

链接仅在用户点击“更新预览”时下载；之后的参数调整和源码更新复用本次内容，不会重复访问订阅服务。再次点击按钮可重新导入。

监听范围是业务源码；修改预览工具自己的服务端实现后需重启服务，修改其前端文件后刷新页面。

## 支持的输入

| 输入 | 行为 |
| --- | --- |
| 逐行节点名称 | 忽略空行和首尾空白，保留 Unicode / 国旗；每行构造一个仅含 `name` 的节点 |
| Clash YAML / JSON | 包含非空 `proxies` 数组或非空 `proxy-providers`；保留连接字段及 provider 定义，实际输出由覆写脚本决定 |
| 公网 HTTP(S) 链接 | 返回上述文本或配置；支持最多 3 次重定向，每一跳均校验目标地址 |

自动识别以 JSON 起始符或 YAML 的 `proxies` / `proxy-providers` 字段为依据。名称文本恰好类似配置语法时，请手动选择“逐行名称”。

限制：

- 不解析 `ss://`、`vmess://` 等协议链接或 Base64 订阅，不展开 `proxy-providers`，不读取需要登录的网页。
- 单次输入或下载不超过 **2 MiB**，最多 **2000** 个节点，单个名称最多 **512** 字符。
- 下载总超时 **10 秒**；请求未压缩文本，若远端仍强制压缩，会提示下载解压后粘贴。
- YAML 限制别名展开数量；改名和覆写执行分别受 **2 秒**的 VM 超时限制。

## provider-only 结构预览

允许粘贴没有 `proxies` 的 `proxy-providers` 配置，也支持混合输入。预览器保留 provider 并展示生成的 `use` 引用，但**不下载快照、不展开 provider（包括 inline payload）、不模拟其动态成员**。改名、地区统计和节点计数仍只处理显式节点；provider-only 输入显示 0 个显式节点，不代表运行时没有节点。由于没有已校验快照，预览不会把 provider 加入前置或落地链路组，也不会从 provider 发现链路。显式落地对应的前置组只展示显式候选，不能据此判断实际 provider 前置可用性。

`providerurl` / `providerinterval` 参数在预览中会明确报错，而不是被忽略或触发自动联网。请移除这两个参数，用已有 provider 定义查看引用结构；完整快照生成应在支持异步入口的 Sub-Store Node 环境中验证，详见[节点订阅 provider](./CONFIGURATION.md#节点订阅-provider-与生成时快照)。

策略组卡片可能没有可显示的显式成员。工具会提示动态成员尚未解析；**预览成功不等于 Mihomo 成功加载、provider 下载成功或节点可连接**。带 `use` 的配置需交给实际 Mihomo 验证更新与成员行为。

## 预览与真实运行的区别

- 使用的是当前 `scripts/substore/rename.ts` 的 `operator()` 和 `src/main.ts` 的 `main()`，不是另外实现一套命名 / 分组规则。
- 名称对照通过仅存在于执行过程的 Symbol 标记追踪节点，支持当前改名脚本的对象复制和排序；标记不会进入最终配置。
- `select` 卡片允许模拟选择，并显示嵌套选择路径。**模拟选择不改变生成配置，也不向节点或 Mihomo 发送请求。**
- `url-test` / `load-balance` 只显示候选成员，不生成假延迟、测速结果或实时选中状态。
- `include-all + filter` 的成员使用当前输入名称和 JavaScript 正则近似展示，并明确提示与 Mihomo / Go 正则的差别。不支持的正则会报告诊断；正则模式可能跨地区匹配或重新包含落地节点，沿用生产配置的实际规则。
- 名称模式没有协议和凭据；仅凭名字不能推断链式代理或 Tailscale 属性。
- 名称被改名脚本移除、未识别地区、未达到 `threshold`、名称重复或与组名冲突等情况，会显示对照或诊断。未识别地区的提示会列出对应节点名称。工具不会为了使界面更好看而修改正式脚本的行为。

## 隐私与网络边界

- 只监听 `127.0.0.1`；校验 Host、Origin 和每次启动生成的会话令牌，不开放跨域 API。
- 节点内容、订阅链接和结果只保留在预览服务进程 / 当前页面内存，不使用浏览器持久存储，也不写日志或工作区。点击“清空”会清理输入及预览；复制、下载是用户显式操作。
- 页面不加载 CDN 图标、远程字体或分析服务。仅在主动导入时，本地服务向指定链接发出网络请求。
- 生成配置可能保留导入的密码、密钥等字段，请勿分享截图或配置中的敏感内容。
- 默认拒绝回环、内网及其他受限地址，DNS 校验结果直接用于连接，重定向同样校验；拒绝 URL 中的用户名 / 密码。
- VM 仅用于执行仓库内可信源码并限制执行时间，**不是执行不可信脚本的安全沙箱**。不要把服务暴露到公网。

### 通过 SSH 隧道访问远端预览

在远端仓库目录运行 `npm run preview`，保持服务只监听 `127.0.0.1:8787`。然后在本机运行：

```bash
ssh -N -L 127.0.0.1:8788:127.0.0.1:8787 user@server
```

浏览器打开 **http://127.0.0.1:8788**。本地与远端端口可以不同，页面资源、源码轮询、预览和链接导入 API 都通过隧道访问，无须把服务暴露到公网。

源码读取、链接下载和 DNS 解析发生在**运行预览服务的那台机器**，不是浏览器所在机器。SSH 隧道只转发网页访问，并不改变服务端 DNS；如链接导入失败，请检查服务端网络 / DNS，或下载内容后粘贴。

## 开发与验证

```text
scripts/preview/
├── input.ts       # 输入格式、参数和规模限制
├── import.ts      # 链接下载及网络边界
├── engine.ts      # 内存编译、真实脚本执行、对照与诊断
├── server.ts      # 本地 HTTP 服务和 CLI
├── types.ts       # 前后端数据接口
└── web/           # 原生 TypeScript、HTML、CSS
```

预览及 provider 回归测试与其他测试一起通过 `npm test` 运行。生产构建和预生成 YAML 不包含预览工具，`npm run artifacts` 的原有行为不变。

可选的真实 Mihomo provider 更新测试（默认跳过，不自动下载内核）：

```bash
MIHOMO_BIN=/绝对路径/mihomo npx tsx --test scripts/tests/provider_runtime.test.ts
```

测试只启动临时内核和回环 HTTP 订阅，不访问生产控制器或真实订阅；隔离分流规则下载、Geo 数据与测速，验证 provider-only / 混合模式的地区及链路成员更新、落地排除、默认链路与字母链路隔离、空候选回退，且无需重载主配置。
